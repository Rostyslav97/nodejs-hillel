# RESTful Form Application

Express приложение для управления пользователями.

## Установка зависимостей

```bash
npm install
```

## Запуск приложения

```bash
npm start
```

Или для режима разработки с автоперезагрузкой:

```bash
npm run dev
```

## Доступные роуты

- `GET /` - Главная страница
- `GET /users` - Список всех пользователей
- `GET /users/create` - Форма для создания пользователя
- `POST /users/create` - Обработка формы создания пользователя

Приложение запускается на http://localhost:3000
