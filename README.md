# Node.js repo

Task 01
Запустіть проєкт командою:
```docker compose up --build -d```

Після завершення збірки, якщо вона пройшла коректно, зайдіть у логи контейнера app, щоб бачити логи Node.js:
```docker compose logs -f app```

У разі необхідності або при виникненні помилок контейнер можна перезапустити командою:
```docker compose restart```


Task 02
Під'єднайтеся до бази даних у створеному контейнері за допомогою MongoDB Compass.
Назва бази даних вказана у конфігураційних файлах проєкту.
Створіть у базі дві колекції:

- articles
- comments

Імпортуйте в них дані з файлів:
- app/data/test.articles.json
- app/data/test.comments.json

Перевірте, що:
- поле _id у колекції articles має тип ObjectId
- поле article у колекції comments також має тип ObjectId


Task 03
Перевірте роботу додатка.
Додаток запускається за адресою:
http://localhost:4500

На головній сторінці виводиться перелік статей.
Також можна перейти на сторінку окремої статті та переглянути саму статтю і коментарі до неї.
На цьому етапі вивід коментарів реалізований не оптимально, але максимально просто.
Завдання - ознайомитися з підходом, який ми будемо покращувати на занятті.


Task 04
Створіть форму у файлі views/form.pug, яка містить:
- поле username
- поле text
- кнопку submit

Підключіть цю форму у файл article.pug.


Task 05
Додайте для форми action за адресою:
```/article/:article_id/comments```

де article_id - це ObjectId поточної статті.

Додайте handler у Node.js для обробки цієї форми.

Код повинен:
- Записувати новий коментар у колекцію comments
- Після цього виконувати redirect на адресу:
```/articles/:article_id```
де article_id - ObjectId поточної статті
